# Folio feature matrix

Legend: **Implemented** = present in this repository; **Foundation** = architecture/schema exists but feature work remains; **Planned** = not yet implemented.

| Feature | Status |
|---|---|
| Native macOS and Android shells | Implemented |
| Local note create/edit/delete | Implemented foundation |
| Search and pinning | Implemented foundation |
| Common versioned document contract | Foundation |
| Folders, nested folders, tags, smart folders | Foundation / Planned |
| Rich text, headings, lists, checklists, tables | Planned |
| Markdown import/export and code blocks | Planned |
| Autosave, undo/redo, note links | Planned |
| Offline-first database and outbox | Foundation |
| Authenticated cross-device sync | Foundation |
| Conflict resolution and version history | Planned |
| Safe Folder with fingerprint + password | Security design / Foundation |
| Encrypted vault attachments and recovery | Planned |
| PDF preview, annotation, OCR, scanning | Planned |
| Drawing, handwriting, handwriting OCR | Planned |
| Audio recording, transcription and timestamps | Planned |
| Web clipper and reading list | Planned |
| AI summaries and action extraction | Planned |
| Infinite canvas and knowledge graph | Planned |
| Templates, journal, study/revision mode | Planned |
| Backup, restore, export and print | Planned |
| Automated unit, UI and sync integration tests | Foundation |

Do not market a planned feature as available. Update this table only after its implementation and tests land.
